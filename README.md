# VALORANT 募集管理 Discord Bot

VALORANTのパーティメンバー募集をDiscord上で管理するBotです。

## 機能

- `/募集` : 人数・ランク帯(ドロップダウン選択)・開始時刻・メモ・リマインド分前を指定して募集を作成
- 「参加する」「キャンセル」ボタンで参加者リストをリアルタイム更新
- 定員に達すると自動で「満員」表示になりボタンが無効化、参加者全員にメンション通知+DM通知
- 開始時刻を `HH:MM`(例: `21:00`)の形式で入力すると、指定分前(デフォルト10分)にチャンネル通知+参加者全員へDMでリマインド
- 参加登録時にも本人へDMで確認通知
- 「締切(募集主のみ)」ボタンで募集主がいつでも手動クローズ可能(締切時はリマインドも自動キャンセル)
- `/募集一覧` : 現在進行中の募集をチャンネル横断で一覧表示

## セットアップ手順

### 1. Discord Developer PortalでBotを作成

1. https://discord.com/developers/applications にアクセス
2. 「New Application」→ 名前を入力(例: Valorant募集Bot)
3. 左メニュー「Bot」→「Add Bot」
4. 「MESSAGE CONTENT INTENT」をONにする(重要)
5. 「Reset Token」でトークンを発行し、コピーしておく

### 2. Botをサーバーに招待

1. 左メニュー「OAuth2」→「URL Generator」
2. Scopes: `bot`, `applications.commands` にチェック
3. Bot Permissions: `Send Messages`, `Embed Links`, `Read Message History`, `Use Slash Commands` にチェック
4. 生成されたURLをブラウザで開き、対象サーバーに招待

### 3. ローカル環境の準備

```bash
pip install -r requirements.txt
cp .env.example .env
# .env を開いて DISCORD_TOKEN=発行したトークン を記入
```

### 4. 起動

```bash
python bot.py
```

起動後、コンソールに `ログイン完了: ...` と表示されれば成功です。
Discord上で `/募集` と入力するとコマンドが使えます(反映まで数分かかる場合があります)。

## 使い方の例

```
/募集 人数:5 ランク帯:ゴールド〜プラチナ 開始時刻:21:00 メモ:デスマ後にランク回します リマインド分前:15
```

これで募集メッセージが投稿され、他のメンバーが「参加する」ボタンを押すと参加者一覧に自動で追加され、
本人にも参加確認のDMが届きます。5人に達すると自動的に満員表示に切り替わり、参加者全員へ通知されます。
開始時刻を `21:00` のように `HH:MM` 形式で入力した場合、指定した分前(例では15分前)に
チャンネルへの通知と参加者全員へのDMリマインドが自動送信されます。

**注意**: `開始時刻` を `今すぐ` や `未定` のような自由文で入力した場合はリマインドは設定されません。
リマインドを有効にしたい場合は必ず `21:00` のような `HH:MM` 形式で入力してください。

## 注意点・制限事項

- 現在の実装では募集情報・リマインドタスクをメモリ上(プログラム実行中のみ)で保持しています。
  Botを再起動すると進行中の募集情報・予約されたリマインドは失われます(投稿済みメッセージ自体は残ります)。
  永続化(再起動後も復元したい)が必要な場合は、SQLiteなどのDB保存+タスクの再スケジュールに拡張できます。
- 1つのBotプロセスで複数サーバーに対応できますが、`/募集一覧` は全サーバー分をまとめて見る設計ではないため、必要に応じてサーバーごとにフィルタする改修も可能です。
- DM通知はユーザーが「サーバーメンバーからのDMを許可」する設定になっている必要があります。拒否設定の場合は自動的にスキップされます(エラーにはなりません)。
- 開始時刻の解析は `HH:MM` 形式のみに対応した簡易パーサーです。入力時刻がすでに過ぎている場合は「翌日の同時刻」として扱われます。

## カスタマイズしたい場合

以下のような拡張がよくある要望です。追加したい場合は教えてください:

- 募集情報をデータベースに保存して再起動しても復元
- ロール(IGL/デュエリスト/センチネル等)ごとの募集枠
- 日付をまたぐ募集(明日の21:00など)への対応
- リマインドを複数回(30分前・5分前など)送る
